# Versioning

V6 keeps version dimensions separate:

- `product_version`
- `api_version`
- `engine_version`
- `schema_version`

P0 baseline:

- product: `0.1.0`
- API: `v1`
- engine: `0.0.0`
- schema: `0`

[PROPOSITION V6] The engine remains `0.0.0` until an actual engine capability is constructed.

`V5_COMPATIBILITY` is a future execution mode, not the V6 product version.
